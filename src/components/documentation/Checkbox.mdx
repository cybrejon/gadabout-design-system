# Checkbox

A checkbox is an interactive control that allows users to select one or more options from a list, or toggle a single binary setting (on/off). Unlike radio buttons, checkboxes support multiple independent selections within a group.  
This component contains two variants: Normal and Indeterminate.

### Indeterminate

Partially filled or dashed box; used programmatically for parent checkboxes in hierarchical lists.

## Usage Guidelines

### When to use

- Use when users need to select one or more independent options from a list.
- Use for a single "accept terms" or "remember me" choice.

### When not to use

- Do not use when only one option can be selected from a group (use Radio buttons).
- Do not use for settings that take effect immediately without a "Submit" or "Save" action (use a Toggle instead).

### Best practices

- Always provide a clear and descriptive label.
- Group related checkboxes together with a logical heading.
