# Metadata

The Metadata component is used to display a labeled piece of information, typically representing a property or attribute of an entity. It uses a structured definition list format, making it ideal for displaying key-value pairs in a semantically correct and visually organized manner.

> **Note:**  
> **The `label` is automatically converted to all-caps to maintain visual consistency and hierarchy across the design system.**

## Usage Guidelines

### When to use
- Use to display specific properties of an item, such as "Date", "Source", or "Author".
- Use within a list or a card where multiple attributes need to be displayed clearly.
- Use when semantic correctness for key-value pairs (using `<dl>`, `<dt>`, `<dd>`) is desired.

### When not to use
- Do not use for large blocks of text; keep the `text` prop concise.
- Do not use for interactive elements or primary actions.
- Avoid using if the information is too prominent and requires more visual weight than a simple label-value pair.

### Best practices
- Keep the `label` short and descriptive.
- Use icons when they provide immediate visual context for the metadata being displayed.
- Align multiple Metadata components to create a clean, organized attribute list.
