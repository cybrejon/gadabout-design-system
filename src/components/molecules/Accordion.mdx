# Accordion

The Accordion component is a vertically stacked set of interactive headings that each contain a title and associated content. It allows users to toggle the visibility of sections of content, saving vertical space and reducing visual clutter.

Built with accessibility in mind utilizing [Bits UI Accordion](https://bits-ui.com/docs/components/accordion) under the hood.

## Usage Guidelines

### When to use

- Use to organize information-heavy pages, such as FAQs, product specifications, or options lists.
- Use when users only need to read one or a few sections of content at a time.
- Use to reduce page scrolling and keep the main content above the fold.

### When not to use

- Do not use if the user needs to read all of the sections simultaneously (in that case, use standard headings and text blocks).
- Do not use if there are very few items (less than 2-3 items) with short content; plain text is cleaner.
- Do not use for primary navigation; use menus or tab systems instead.

### Best practices

- Label the section headings clearly and descriptively.
- Order the accordion items logically (e.g., most frequently asked questions first).
- Use `type="single"` when users should focus on one topic at a time, and `type="multiple"` when comparison between sections is helpful.
