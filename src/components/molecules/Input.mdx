# Input

The Input component allows users to enter and edit text or numeric data. It is typically used within forms to collect information such as names, email addresses, or passwords. Unlike Textareas, Input components are designed for single-line entries.

## Usage Guidelines

### When to use

- Use for capturing short, single-line text data like names, email addresses, or search terms.

### When not to use

- Do not use for long-form text (use a TextArea instead).
- Avoid using for simple on/off choices (use a Toggle or Checkbox).

### Best practices

- Always include a label for accessibility.
- Use the `placeholder` prop to provide a hint about the expected format, but do not use it as a replacement for a label.
- Use the appropriate `type` (e.g., `email`, `password`) to enable browser-specific features and validations.
