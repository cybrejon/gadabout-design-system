# Toggle

A toggle is a button that can be in one of two states: on or off. It is used for binary settings or preferences that take effect immediately.
Gadabout's toggle is built on top of the Button component and maintains a consistent aesthetic while providing clear visual feedback for its active state.

## Usage Guidelines

### When to use

- Use for binary settings that take effect immediately when changed.
- Use for "On/Off" or "Show/Hide" interactions.

### When not to use

- Do not use in forms where the change should only be saved when the user clicks "Submit". Use a Checkbox instead.

### Best practices

- Ensure the label clearly indicates what is being toggled.
- Use the `pressed` state to visually distinguish between the "on" and "off" states.
