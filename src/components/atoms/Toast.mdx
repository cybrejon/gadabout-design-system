# Toast

A succinct message that is displayed temporarily.

Toasts are triggered programmatically via the `toast` function and rendered using the `Toaster` component in your root layout.

## Usage

```javascript
import { toast } from 'import-path';

toast("Event has been created", {
  description: "Sunday, December 03, 2023 at 9:00 AM",
});
```

## API Reference

The `toast` function accepts a title string and an optional `ToastOptions` object.
