## Usage Guidelines

### When to use

- Use to provide a text description for form elements like inputs, checkboxes, and toggles.

### Best practices

- Labels should be concise and clearly describe the associated input.
- For accessibility, ensure the label is programmatically linked to its input (handled automatically in our composite components).
