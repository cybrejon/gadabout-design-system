# Spinner

A spinner is used to indicate a loading state or a process that is taking place.
It provides visual feedback to the user that the system is busy and working on their request.

## Usage Guidelines

### When to use

- Use a spinner when an action takes more than 1 second to complete.
- Use a spinner for background processes that the user should be aware of.
- Place the spinner in the context of the action (e.g., inside a button or in the center of a loading list).

### When not to use

- Do not use a spinner if the action is expected to be nearly instantaneous.
- For long-running processes where progress can be measured, use the `Progress` component instead.
- Avoid using multiple spinners on the same screen if possible.

### Best practices

- Always provide an `aria-label` for screen readers (defaults to "Loading...").
- Ensure the spinner's color has sufficient contrast against the background.
